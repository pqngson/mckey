# Hotkey layout repair — 2026-11-04
**Status:** done
**Commits:** working tree changes in McKey/Theme.swift, McKey/Settings/SettingsComponents.swift, McKey/Settings/HotkeySettingsView.swift

**Did / Deciding:**
Fixed screenshot-reported hotkey modifier button and shortcut recorder layout overflow in the 168pt settings control column.

Root cause: `Toggle(title)` combined with `.labelsHidden()` and `.toggleStyle(.button)` on macOS SwiftUI failed to hide the button label title, causing overlay text to draw directly on top of the button label. Replaced with `Toggle(isOn:) { Text(label) }` using simple symbol text, removing `.labelsHidden()` and `.overlay(...)`. Added explicit `accessibilityLabel(title)` and `help(title)` for VoiceOver and hover discovery.

Centralized layout tokens under `McKeyTheme.Hotkeys`:
- `modifierButtonWidth = 28pt`
- `modifierSpacing = 6pt`
- `modifierFontSize = 13pt`
- `recorderWidth = 140pt`

Removed obsolete `McKeyTheme.Layout.recorderWidth = 168pt` after confirming `SettingsComponents.swift` was its sole consumer.

Arithmetic:
- Modifier row: 5 buttons * 28pt + 4 gaps * 6pt = 140pt + 24pt = 164pt <= 168pt column width.
- Shortcut recorder: 140pt recorder width allows clear button and spacing to fit inside the 168pt column.
- Fn label displays "fn".

No runtime, settings model, project, or planner documentation modifications made. Visual layout fix only; no GUI verification claimed.
