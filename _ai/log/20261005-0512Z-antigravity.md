## Mechanism & Trace Details

### Switch Paths & `lastActivityAt`
Every language switch path calls `languageDidSwitch()`, which sets `lastActivityAt = ProcessInfo.processInfo.systemUptime`:
1. **Chord shortcut (`tap.onLanguageToggle`)**: `handleFlagsChanged` toggles `enabled` and fires `onLanguageToggle`, which dispatches to `AppDelegate.languageDidSwitch()`.
2. **Status-bar Menu click (`toggleEnabled()`)**: toggles `tap.enabled` and immediately calls `languageDidSwitch()`.
3. **Idle Auto-switch timer (`handleAutoSwitchTick()`)**: if `now - max(tap.lastKeyAt, lastActivityAt) >= Double(autoSwitchDelay)`, sets `tap.enabled = target` and calls `languageDidSwitch()`.
4. **ControlPanel Apply (`apply()`)**: calls `app.noteActivity()`, which sets `lastActivityAt = now`.

Because every switch updates `lastActivityAt`, on the next 1 s timer tick `now - max(tap.lastKeyAt, lastActivityAt)` is ~1.0 s, which is strictly less than `autoSwitchDelay` (>= 5 s). Switches made after long idle periods are never reverted by the timer.

### Screen Coordinate Flip
Conversion from AX top-left primary-screen coordinates to Cocoa bottom-left coordinates in `FocusProbe.focusedTextCaret()`:
```swift
if let primary = NSScreen.screens.first {
    let cocoaY = primary.frame.height - rect.origin.y - rect.height
    return NSRect(x: rect.origin.x, y: cocoaY, width: rect.width, height: rect.height)
}
```
